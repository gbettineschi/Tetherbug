Personal fork of [xav-ie/Tetherbug](https://github.com/xav-ie/Tetherbug), with patches for both platforms.

**Android (versionCode 106)**

- Rebuilds Bluetooth advertising and the GATT server after Bluetooth is switched off and on.
- Restores bonded status subscriptions across app updates and server replacement.
- Reports Shizuku readiness changes to the Mac without requiring a manual reconnect.
- Allows service startup with notifications denied; Android may still show its system foreground-service indicator.
- Leaves the phone's native unused-hotspot timeout settings alone.
- Signed with the same personal certificate as `0.1.1-btfix.4`; an in-place update preserves app data. Official upstream APKs use a different key.

**macOS (Apple Silicon and Intel, macOS 14+)**

- Native menu with a blue Mobile Hotspot switch, device name, Automatic mode and pause status.
- Stable menu-bar icon during requests; turning the hotspot off in Automatic mode pauses activation for 15 minutes.
- Native settings, helper startup recovery, late Bluetooth discovery and connection retries.
- Closing settings keeps the menu bar running; Quit exits the app and helper.
- Existing automatic activation policy is retained, including when a Mac deliberately remains awake with its lid closed.

The Samsung S23 can be controlled over Bluetooth, but its tested firmware does not broadcast the requested Apple marker. This release does **not** fix the linked-ring Wi-Fi icon or add Apple Continuity discovery.

Add `https://github.com/gbettineschi/Tetherbug` to Obtainium. Each release has one APK, so no asset filter is needed. Future updates must come from this fork to retain these patches.

The Mac download is ad-hoc signed and not notarized. macOS may require approval under System Settings → Privacy & Security, and Bluetooth permission may need reapproval after an update. No automatic Mac updater is embedded.

The recovery changes were previously tested on a physical S23. This release re-runs the automated suites and verifies the retained Android certificate; it does not claim a new physical-device test of this packaging-only version bump.
